Introduction概要

com.confusedgamedev.vfx is a UPM package of 60 real-time visual effects and 46 game objects for the Universal Render Pipeline, ported from the Three.js library at 00gamedevs.com (MIT, see THIRD-PARTY-NOTICES.md). Each effect is a prefab with a preset asset and procedural shaders; no texture or particle system is needed. Objects are baked meshes, and the weapons and turrets among them can fire. It is for Unity developers who want the site's effects in a game.

com.confusedgamedev.vfx は、00gamedevs.com の Three.js ライブラリ（MIT、THIRD-PARTY-NOTICES.md 参照）から移植した、Universal Render Pipeline 向けリアルタイム VFX 60種とゲームオブジェクト46種の UPM パッケージです。各エフェクトはプレハブ、プリセットアセット、プロシージャルシェーダーで構成されます。オブジェクトはベイク済みメッシュで、武器とタレットは発射できます。サイトのエフェクトをゲームで使いたい Unity 開発者を対象としています。

Status: version 0.1.0, on Unity 6000.5.3f1 and URP 17.5.0, with 215 EditMode tests passing.

現状：バージョン 0.1.0、Unity 6000.5.3f1 と URP 17.5.0 に対応し、EditMode テスト 215 件がすべて成功しています。

Instructions使い方

Installインストール

  1. Use Unity 6000.5 with URP 17.5.0.
  2. Copy Packages/com.confusedgamedev.vfx into your project's Packages folder, or add it by Git URL with the path query.
  3. Find prefabs under Runtime/Effects/<Name>/Assets/.
  1. Unity 6000.5 と URP 17.5.0 を用意します。
  2. Packages/com.confusedgamedev.vfx をプロジェクトの Packages にコピーするか、path クエリ付きの Git URL で追加します。
  3. プレハブは Runtime/Effects/<Name>/Assets/ にあります。
Effects marked * in the catalog sample the scene: turn on Opaque Texture in every URP asset you ship. PC_RPAsset has it on; Mobile_RPAsset has it off, so they look wrong there until enabled.一覧で * の付いたエフェクトはシーンをサンプリングします。出荷するすべての URP アセットで Opaque Texture を有効にしてください。PC_RPAsset は有効、Mobile_RPAsset は無効のため、有効にするまで正しく表示されません。

Impact Frame setupImpact Frame の設定

  1. Select each Universal Renderer Data asset in use.
  2. Add Renderer Feature > Impact Frame.
  3. Check its Shader field holds ConfusedGameDev/Vfx/ImpactFrame.
  4. Add an ImpactFrameTrigger to any object.
  1. 使用中の Universal Renderer Data アセットをそれぞれ選択します。
  2. Add Renderer Feature > Impact Frame を実行します。
  3. Shader 欄が ConfusedGameDev/Vfx/ImpactFrame であることを確認します。
  4. 任意のオブジェクトに ImpactFrameTrigger を追加します。

Tutorial: cast a fireballチュートリアル：火球を放つ

  1. Drag Runtime/Effects/Fireball/Assets/Fireball.prefab into a scene. Expected: the Inspector shows the preset with Play, Stop and Replay, previewing outside Play mode. To loop every effect in the open scenes, turn on Tools > ConfusedGameDev > VFX > Preview All Effects In Edit Mode.
  2. Change color in the embedded preset. Expected: the preview updates at once.
  3. Add the script below and assign the prefab to fireballPrefab.
  4. Call Cast, then Hit() on collision. Expected: the bolt flies, bursts and removes itself.
  1. Runtime/Effects/Fireball/Assets/Fireball.prefab をシーンにドラッグします。Inspector にプリセットと Play、Stop、Replay が表示され、Play モード外でもプレビューできます。開いているシーンの全エフェクトをループ再生するには、Tools > ConfusedGameDev > VFX > Preview All Effects In Edit Mode をオンにします。
  2. 埋め込まれたプリセットの color を変更します。プレビューがすぐに更新されます。
  3. 下のスクリプトを追加し、fireballPrefab にプレハブを割り当てます。
  4. Cast を呼び、衝突時に Hit() を呼びます。火球が飛び、炸裂して自動的に消えます。
using ConfusedGameDev.Vfx;
using UnityEngine;

public class Caster : MonoBehaviour
{
    [SerializeField] private FireballEffect fireballPrefab;

    public void Cast(Vector3 from, Vector3 direction)
    {
        FireballEffect shot = Instantiate(fireballPrefab, from, Quaternion.identity);
        shot.onFinished.AddListener(() => Destroy(shot.gameObject));
        shot.Play();
        shot.SetDirection(direction); // only takes effect while playing
    }
}

API referenceAPIリファレンス

VfxEffect

Abstract [ExecuteAlways] base of every prefab effect. Values reach shaders through a MaterialPropertyBlock, so instances stay independent.

プレハブ型エフェクトすべての抽象基底クラス（[ExecuteAlways]）です。値は MaterialPropertyBlock でシェーダーへ渡すため、インスタンスは互いに独立します。

public VfxState State { get; }        // Idle, Playing, Stopping, Finished
public float EffectTime, Fade, StartProgress, EndProgress { get; }
public bool IsPlaying { get; }
public VfxPreset Preset { get; }
public VfxPreset RuntimeParameters { get; }  // private clone, made on first access
public UnityEvent onFinished;

public void Play();
public void Stop(bool immediate = false);
public void SetPreset(VfxPreset newPreset);
public void Tick(float deltaTime);          // Update calls this in Play mode
public void ApplyParameters();              // call after changing RuntimeParameters

protected virtual void OnPlay();
protected virtual void OnTick(float deltaTime);
protected virtual void OnApplyParameters(MaterialPropertyBlock block, VfxPreset parameters);
VfxPreset

Abstract ScriptableObject. Every effect ships a <Name>_Default.asset holding the site defaults.

抽象 ScriptableObject です。各エフェクトには、サイトの既定値を持つ <Name>_Default.asset が付属します。

public Color color;
[Range(0.25f, 2f)] public float size, speed, detail;
[Range(0.125f, 1f)] public float density;
public VfxPlayback playback;     // OneShot, Looping
public float duration, startDuration, stopDuration;
public VfxEndAction endAction;   // None, Disable, Destroy, ReturnToPool
VfxProjectileEffect

Flight and impact. Hit with no arguments detonates at the current contact point.

飛翔と着弾を担当します。引数なしの Hit は現在の接触点で炸裂します。

public void SetDirection(Vector3 direction, float speed = 4f);
public void Hit(Vector3? worldPoint = null, Vector3? worldNormal = null);

Length drives the root Z scale, so a manual Z scale is overwritten every update.

Length はルートの Z スケールを制御します。手動で設定した Z スケールは毎回上書きされます。

public float Length { get; set; }

public Vector2Int LayerCounts(float density);

VfxObjectFiring

Fire restarts the shot. Every point fires, except on the missile turret, which uses its next pod. An unknown pointId throws. Play() repeats the last shot's points and target. Shots are drawn with Graphics.RenderMesh, so they add no scene objects.

Fire は射撃を最初から再生します。すべての発射点が撃ちますが、ミサイルタレットだけは次のポッドを使います。不明な pointId は例外になります。Play() は前回の発射点と標的で再生します。射撃は Graphics.RenderMesh で描画するため、シーンにオブジェクトは増えません。

public VfxFiringKind Kind { get; }
public float Range { get; }                  // world units, with no target
public int ActivePointCount { get; }
public Camera RenderCamera { get; set; }     // null draws for every camera
public void Fire(string pointId = null, Vector3? worldTarget = null);
public void StopFire();
public void DrawFrame();                     // LateUpdate calls this
public static float DurationOf(VfxFiringKind kind);
public static float RangeOf(VfxFiringKind kind);
ImpactFrameTrigger / ImpactFrameFeature

Full-camera post-process. Triggers are not queued.

カメラ全体へのポストプロセスです。トリガーはキューされません。

Vector3 viewport = camera.WorldToViewportPoint(hitPoint);
trigger.Fire(viewport, attackDirection);   // false while a sequence runs
// also: SetCenter, Cancel, subjects, subjectMask, sequence

General usage一般的な使用法

  • Edit RuntimeParameters for per-instance changes, then call ApplyParameters; this leaves the asset untouched.
  • Shaders compute motion in the vertex stage from _EffectTime, so nothing is simulated on the CPU. Blade trails are the exception: they sample the weapon each frame.
  • To add an effect: derive a preset and effect, build meshes, and mark a builder with [VfxBuilder("Name")].
  • A source FrontSide material needs Cull Front because positions go through the .zyx axis swap.
  • Black Hole is the heaviest effect, and its cost is unmeasured.
  • インスタンスごとの変更は RuntimeParameters を編集して ApplyParameters を呼びます。アセットは変更されません。
  • シェーダーは _EffectTime から頂点段階で動きを計算するため、CPU でのシミュレーションはありません。例外は武器の軌跡で、毎フレーム武器をサンプリングします。
  • エフェクトの追加は、プリセットとエフェクトを派生し、メッシュを作り、ビルダーに [VfxBuilder("Name")] を付けます。
  • 元の FrontSide マテリアルは、座標が .zyx で軸変換されるため Cull Front が必要です。
  • Black Hole は最も重いエフェクトで、負荷は未計測です。

Objectsオブジェクト

The package also holds 46 game objects baked from the same site. Each folder under Runtime/Objects has a prefab, a mesh with one submesh per colour role, its materials and a README. Units are meters.

パッケージには、同じサイトからベイクしたゲームオブジェクト46種も含まれます。Runtime/Objects 配下の各フォルダーには、プレハブ、色の役割ごとにサブメッシュを分けたメッシュ、マテリアル、README があります。単位はメートルです。

Place and recolour配置と色の変更

  1. Drag Runtime/Objects/<Name>/<Name>.prefab into a scene.
  2. Set primary, secondary and accent on VfxObject, or call SetColors. ResetColors restores the defaults.
  1. Runtime/Objects/<Name>/<Name>.prefab をシーンにドラッグします。
  2. VfxObject の primary、secondary、accent を設定するか、SetColors を呼びます。ResetColors で既定値に戻ります。

Fire a weapon武器を発射する

The pistol, the rifle and the five turrets carry VfxObjectFiring, a VfxEffect that plays one shot per Fire and leaves the object in place. The shot is visual only: it does no damage and has no collision.

  3. 下のスクリプトを追加し、タレットと標的を割り当てます。Shoot を呼ぶと、その時点の標的の位置へビームが向きます。タレットのモデル自体は回転しません。
using ConfusedGameDev.Vfx;
using UnityEngine;

public class TurretController : MonoBehaviour
{
    [SerializeField] private VfxObjectFiring turret;
    [SerializeField] private Transform enemy;

    public void Shoot()
    {
        turret.Fire(worldTarget: enemy.position);
    }
}

Fire points are child transforms that aim along their own +Z, so VfxObject.FindFirePoint(id) also gives you a spot to attach your own effects. Each object README lists its point ids.

発射点は自身の +Z を向く子 Transform です。VfxObject.FindFirePoint(id) で取得すれば、独自のエフェクトの取り付け位置にも使えます。発射点の ID は各オブジェクトの README に記載しています。
